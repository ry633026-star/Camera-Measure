# Camera Measure – Android App

Camera Measure is an Android application developed to measure the
distance and height of real-world objects using a mobile camera,
device sensors, and image processing techniques.

## Features
- Live camera-based distance & height measurement
- Uses accelerometer and gravity sensors for angle calculation
- Offline image measurement using reference objects
- Region growing image processing technique

## Technologies Used
- Java
- Android SDK
- Camera API
- Accelerometer & Gravity Sensors
- Image Processing
